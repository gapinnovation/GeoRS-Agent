# Instruction used for the image-based tests

Each image was submitted on its own, in a new conversation with the configured agent, together with the same instruction. The ground-truth class was not mentioned.

> Identify the visible objects, dominant colours and geometric patterns in this image. Return the most plausible scene class and any alternative classes, and provide an attribute-grounded explanation and an uncertainty note.
